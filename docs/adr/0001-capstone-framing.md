- **Status:** Draft v1
- **Date:** 2026-08-20
- **Author:** Tushar Sawant


## Context
This capstone focuses on the IT/Software industry to solve their problems using government policies regarding IT resources, policies, guidelines on use of devices on goverment network etc

## Decision — Solution Framing Canvas

| Box | Your answer |
|-----|-------------|
| **Inputs** | Pdfs, images, docx |
| **Outputs** | a text answer, a citation list, a structured result |
| **Tools** | OpenAI, LLM, vector database |
| **Memory** | nothing, last N turns, durable history |
| **Autonomy level** | on the spectrum this to be an agentic system |
| **Decision boundaries** | It's allowed to decide on its own the next step for the IT industy to take. |

## Consequences

- **Positive:** Goverment policy documents are difficult to understand for normal person. This agentic system will help to provide the answers in Natural language.
- **Negative / risks:** Policies might change over the period of time, so need to be updated with the latest policy goverment impose in future.
- **Things we'll re-visit:** Country-wise goverment policys + state-wise policies
